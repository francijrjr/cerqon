# CERQON CLI

Open-source security scanner for local AI agent and MCP configurations.

The npm artifact bundles internal CERQON modules. Third-party runtime dependencies
are declared in package.json. No separately published @cerqon libraries are needed.

Run `cerqon scan . --json` to report findings, or add `--fail-on high` to enforce a
security threshold. See the repository README for limitations and scan status.
