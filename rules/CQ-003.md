# CQ-003: Exposed Agent Secret

- **Severity**: `CRITICAL`
- **Category**: `secrets`
- **Status**: `Active (0.1)`

## Description
Detects hardcoded API keys, tokens, database credentials, or private cryptographic keys stored directly in agent configuration files or MCP `env` blocks.

## Impact
Plaintext credentials committed to source code or configuration files can be leaked via agent prompts, logged in traces, or stolen if repository access is compromised.

## Recommendation
Inject credentials via runtime environment variables (e.g. `${OPENAI_API_KEY}`) or use a secure secret vault instead of committing plaintext tokens.

## Example

### Non-Compliant
```json
{
  "mcpServers": {
    "llm-tools": {
      "command": "node",
      "args": ["server.js"],
      "env": {
        "OPENAI_API_KEY": "sk-proj-99887766554433221100aabbccddeeffgghh"
      }
    }
  }
}
```

### Compliant
```json
{
  "mcpServers": {
    "llm-tools": {
      "command": "node",
      "args": ["server.js"],
      "env": {
        "OPENAI_API_KEY": "${OPENAI_API_KEY}"
      }
    }
  }
}
```
