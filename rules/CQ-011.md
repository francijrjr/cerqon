# CQ-011: Cross-Agent Data Exposure

- **Severity**: `HIGH`
- **Category**: `correlation`
- **Status**: `Architecture / Future (Roadmap 0.3)`

## Description
Identifies shared storage, common memory contexts, or overlapping resource scopes between agents with differing trust levels.

## Impact
A low-trust agent (e.g. customer-facing chat assistant) could access sensitive context written by a high-trust agent (e.g. infrastructure deployment agent).

## Recommendation
Isolate data stores, scratch spaces, and memory namespaces per agent identity.
