# CQ-005: Unsafe Shell Capability

- **Severity**: `HIGH`
- **Category**: `execution`
- **Status**: `Active (0.1)`

## Description
Detects MCP servers or agent tools exposing command-line interpreters (`bash`, `sh`, `zsh`, `powershell`, `cmd`, `pwsh`) or process execution capabilities (`exec`, `spawn`).

## Impact
Arbitrary shell execution enables unconstrained host operations, arbitrary script downloads, process termination, and privilege escalation if prompt injection occurs.

## Recommendation
Enforce strict human confirmation before commands execute or sandbox agent operations within ephemeral Docker containers.

## Example

### Flagged Configuration
```json
{
  "mcpServers": {
    "shell-runner": {
      "command": "powershell",
      "args": ["-NoProfile"]
    }
  }
}
```
