# CQ-001: Excessive Tool Permission

- **Severity**: `HIGH`
- **Category**: `permissions`
- **Status**: `Architecture / Future (Roadmap 0.2)`

## Description
Detects agent tools configured with wildcard or overly broad action permissions that exceed operational necessity.

## Impact
Excessive capabilities allow an agent to perform mutating actions beyond its designated scope if prompt boundaries fail or if malicious instructions are injected.

## Recommendation
Apply the principle of least privilege by scoping tool permissions to explicit read/write subsets.
