# CQ-004: Excessive OAuth Scope

- **Severity**: `MEDIUM`
- **Category**: `permissions`
- **Status**: `Architecture / Future (Roadmap 0.2)`

## Description
Flags third-party integrations or agent tool manifests requesting administrative or overly broad OAuth authorization scopes.

## Impact
Tokens with wide scopes allow compromised agents to read, modify, or delete sensitive SaaS data across the entire organization.

## Recommendation
Request granular, resource-specific OAuth scopes (e.g. `repo:status` instead of full `repo` admin).
