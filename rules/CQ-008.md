# CQ-008: Agent Network Exposure

- **Severity**: `HIGH`
- **Category**: `network`
- **Status**: `Architecture / Future (Roadmap 0.2)`

## Description
Flags agent listeners or MCP servers bound to public interfaces (`0.0.0.0`) without authentication or network access control.

## Impact
Exposing agent execution endpoints to the open network allows unauthenticated third parties to inject prompts or invoke tools remotely.

## Recommendation
Bind agent services exclusively to localhost (`127.0.0.1`) or require mutual TLS (mTLS) / bearer token authentication.
