# CQ-012: Dangerous Capability Chain

- **Severity**: `CRITICAL`
- **Category**: `correlation`
- **Status**: `Architecture / Future (Roadmap 0.3)`

## Description
Detects toxic combinations of capabilities that, when chained together, form an autonomous exploit or exfiltration pipeline (e.g. Filesystem Read + Secret Access + Outbound Network/Shell).

## Impact
While individual capabilities may seem innocuous on their own, an agent possessing both read access to sensitive assets and unrestricted outbound communication channels can automatically exfiltrate credentials or sensitive user data.

## Recommendation
Enforce composite separation-of-duty boundaries preventing agents with read access to secrets from having arbitrary outbound transmission capabilities.
