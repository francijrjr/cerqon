# CQ-002: Unrestricted Filesystem Access

- **Severity**: `CRITICAL`
- **Category**: `filesystem`
- **Status**: `Active (0.1)`

## Description
Flags MCP filesystem servers or agent tools configured with unrestricted, root (`/`, `C:\`), or sensitive operating system directory mounts.

## Impact
Mounting root or high-level parent directories grants the AI agent access to sensitive files across the entire host OS, including `/etc/passwd`, SSH keys, browser credentials, and system binaries.

## Recommendation
Constrain the MCP filesystem server arguments strictly to the project's working directory (e.g. `./workspace` or `/home/user/project/src`).

## Example

### Non-Compliant
```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/"]
    }
  }
}
```

### Compliant
```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "./projects/app-data"]
    }
  }
}
```
