# CQ-006: Unverified MCP Source

- **Severity**: `HIGH`
- **Category**: `supply-chain`
- **Status**: `Active (0.1)`

## Description
Identifies MCP servers using mutable package references or direct remote sources without immutable pins. Network transport and approval are reported by CQ-008 and CQ-007 respectively.

## Impact
Cleartext transports expose context and prompts to eavesdropping and manipulation. Wildcard approval bypasses human review, enabling fully autonomous destructive behavior.

## Recommendation
Require TLS (HTTPS/WSS) for remote connections, avoid remote unpinned commands, and replace wildcard approvals with explicit tool whitelists.
