# CQ-007: Missing Human Approval

- **Severity**: `MEDIUM`
- **Category**: `governance`
- **Status**: `Architecture / Future (Roadmap 0.2)`

## Description
Checks whether mutating, destructive, or outbound network actions require human-in-the-loop validation.

## Impact
Unsupervised actions can lead to accidental data loss, unintended database mutations, or unreviewed deployments.

## Recommendation
Enforce interactive confirmation prompts on all non-idempotent tool calls.
