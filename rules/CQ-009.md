# CQ-009: Tool Definition Drift

- **Severity**: `LOW`
- **Category**: `supply-chain`
- **Status**: `Architecture / Future (Roadmap 0.2)`

## Description
Detects discrepancies between local tool parameter definitions and cryptographically signed registry definitions.

## Impact
Silent modification of tool parameters may indicate supply chain tampering or unreviewed changes introducing security bypasses.

## Recommendation
Pin tool definitions to immutable hashes verified against a trusted policy repository.
