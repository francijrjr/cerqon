# CQ-010: Missing Audit Trail

- **Severity**: `LOW`
- **Category**: `governance`
- **Status**: `Architecture / Future (Roadmap 0.2)`

## Description
Flags configurations where execution logging, prompt recording, or session audit logging is disabled or omitted.

## Impact
Lack of immutable audit logs impairs forensic investigation, root cause analysis, and compliance verification following a security breach.

## Recommendation
Enable structured JSON logging for all agent tool invocations, session states, and outputs.
